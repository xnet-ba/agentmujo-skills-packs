# native-ui

## Purpose
Design and implement native mobile UI patterns

## Guidance
- Inspect the current mobile project, platform configuration, package versions, and relevant tooling before making changes.
- Prefer project conventions and supported platform APIs.
- Make small, reviewable changes.
- Use AgentMujo Core Skills for planning, research, debugging, verification, and reporting.
- Test affected functionality before completion.
- Consider platform-specific behavior where relevant.
- Never expose credentials, tokens, signing keys, or other sensitive project data.

## Expected Output
Report relevant findings, changes made, validation performed, resulting state, and remaining risks.
