# Engineer Skill Design

Engineer skills should:

- focus on systems, architecture, reliability, risk, quality, and technical decisions
- be composable with AgentMujo Core Skills and specialist packs
- make assumptions and constraints explicit
- prefer measurable evidence over unsupported conclusions
- separate analysis from execution
- verify important outcomes
- document significant technical decisions and residual risks

Avoid duplicating generic Core Skills unless a specialized engineering workflow requires a domain-specific adaptation.
