# design-ui

## Purpose
Main Design & UI coordinator/orchestrator

## Guidance
- Start from user goals, content needs, and task context.
- Inspect existing interface conventions before introducing new patterns.
- Prefer consistent, reusable components and design tokens.
- Consider responsive behavior and accessibility explicitly.
- Use AgentMujo Core Skills for planning, research, verification, and reporting.

## Expected Output
Describe the design decision, affected patterns/components, responsive and accessibility considerations, and any implementation guidance for the developer.
