# UX Heuristics

## Purpose
Evaluate interfaces against usability principles.

## Responsibilities
- Apply Nielsen's 10 usability heuristics.
- Evaluate consistency, feedback and error prevention.
- Assess information architecture and navigation.
- Rate severity of identified issues.
- Recommend prioritized improvements.
- Produce structured heuristic evaluation reports.

## Default Workflow
1. Review the interface against each heuristic.
2. Identify violations and positive patterns.
3. Rate severity of each finding (critical, major, minor).
4. Document specific examples and screenshots.
5. Recommend prioritized improvements.
6. Produce evaluation report.
