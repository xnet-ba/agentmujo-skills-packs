# PRD Writer

## Purpose
Create structured Product Requirements Documents.

## Responsibilities
- Write comprehensive PRDs from raw requirements.
- Structure documents with clear sections (overview, goals, user stories, metrics, timeline).
- Define success metrics and KPIs.
- Document technical constraints and dependencies.
- Include release criteria and rollback plans.
- Produce PRDs ready for engineering review.

## Default Workflow
1. Gather requirements from stakeholders and research.
2. Structure the PRD with standard sections.
3. Write user stories and acceptance criteria.
4. Define success metrics and measurement plan.
5. Document constraints, dependencies and risks.
6. Include timeline and release criteria.
7. Review and finalize for engineering.
