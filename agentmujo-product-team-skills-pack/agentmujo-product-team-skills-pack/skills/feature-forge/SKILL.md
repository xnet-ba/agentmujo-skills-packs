# Feature Forge

## Purpose
Write requirements, user stories and acceptance criteria.

## Responsibilities
- Write clear, testable user stories.
- Define acceptance criteria and edge cases.
- Document functional and non-functional requirements.
- Identify dependencies and constraints.
- Ensure requirements are ready for engineering.
- Validate completeness and clarity.

## Default Workflow
1. Understand the feature context and user need.
2. Write user stories in standard format.
3. Define acceptance criteria for each story.
4. Identify edge cases and error scenarios.
5. Document non-functional requirements.
6. Review for completeness and clarity.
7. Prepare for engineering handoff.
