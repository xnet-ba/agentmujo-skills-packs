# Product Manager

## Purpose
Product framing, prioritization and feature shaping.

## Responsibilities
- Frame problems and opportunities with clear context.
- Prioritize features using structured frameworks (RICE, ICE, impact/effort).
- Shape features with user stories and acceptance criteria.
- Balance user needs, business goals and technical constraints.
- Make trade-offs explicit and evidence-based.
- Communicate product decisions to stakeholders.

## Default Workflow
1. Frame the problem or opportunity.
2. Gather evidence from research, data and stakeholders.
3. Evaluate options using prioritization framework.
4. Shape the selected feature(s) with clear scope.
5. Define success metrics and validation criteria.
6. Hand off to engineering with clear specifications.
