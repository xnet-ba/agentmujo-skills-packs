# security-audit

## Purpose
Main Security coordinator/orchestrator

## Responsibilities
- Coordinate security-related skills for the current task.
- Establish scope and authorization assumptions before intrusive checks.
- Prioritize findings by impact, likelihood, and exploitability.
- Coordinate remediation and verification.

## Workflow
1. Define scope.
2. Gather evidence.
3. Assess threats and vulnerabilities.
4. Prioritize risk.
5. Recommend or apply remediation within authorized scope.
6. Verify the result.
7. Report findings and remaining risk.
