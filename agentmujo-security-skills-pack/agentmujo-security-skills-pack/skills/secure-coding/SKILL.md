# secure-coding

## Purpose
Apply secure software development practices

## Guidance
- Work only within the authorized scope.
- Prefer evidence from source code, configuration, logs, dependencies, and documented system behavior.
- Minimize exposure of secrets and sensitive information.
- Distinguish confirmed findings from hypotheses.
- Recommend practical remediation and verify the resulting state.
- Use AgentMujo Core Skills for planning, research, debugging, verification, and reporting.

## Expected Output
Report scope, relevant evidence, findings, severity or risk, recommended remediation, verification performed, and remaining uncertainties.
