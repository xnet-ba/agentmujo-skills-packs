# Skill Design

Linux Server Admin Skills are operational skills. They focus on diagnosis, safe changes, verification, and reporting for Linux infrastructure.

## Boundaries

- General agent workflow belongs to AgentMujo Core Skills.
- Linux/server-specific procedures belong here.
- Vendor-specific or cloud-specific instructions should be added to specialist packs when possible.
- Destructive actions require explicit risk evaluation and post-change verification.

## Preferred Pattern

```text
Observe → Diagnose → Plan → Verify → Change → Verify → Report
```
