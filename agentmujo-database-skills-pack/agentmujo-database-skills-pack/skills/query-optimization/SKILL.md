# query-optimization

## Purpose
Analyze and optimize slow or inefficient queries

## Guidance
- Inspect the current database environment before making changes.
- Confirm the target database, schema, scope, and intended effect.
- Prefer safe, incremental and reversible operations where practical.
- Use AgentMujo Core Skills for planning, research, debugging, verification, and reporting.
- Protect credentials and sensitive data.
- Verify database state and application impact after changes.

## Expected Output
Report findings, changes, validation performed, resulting state, and remaining risks.
