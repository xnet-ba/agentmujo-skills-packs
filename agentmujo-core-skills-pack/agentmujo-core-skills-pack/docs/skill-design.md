# Core Skill Design Guidelines

Core skills are shared capabilities, not job-specific procedures.

## Principles

- Keep instructions role-neutral.
- Prefer evidence over assumptions.
- Load the smallest useful skill set.
- Separate planning from execution when risk warrants it.
- Verify important outputs before completion.
- Avoid exposing sensitive information.
- Produce concise, auditable reports for consequential work.
- Defer domain-specific details to role or specialist packs.

## Composition

A core skill may call or coordinate other skills conceptually, but it should not hard-code the implementation details of a specific vendor, framework, operating system, or business domain.
