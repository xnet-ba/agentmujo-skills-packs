# Technical Reporting

Use for operational or engineering reports.

## Structure
- Summary
- Environment/context
- Findings/evidence
- Actions performed
- Current status
- Risks/issues
- Recommendations
- Next checks

Never present an unverified hypothesis as a fact. Record commands/actions only when actually performed.
