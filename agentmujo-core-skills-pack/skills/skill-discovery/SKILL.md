# Skill Discovery

Use this skill when deciding which installed skills are relevant to a task.

## Procedure
1. Inspect the available skill names/descriptions.
2. Map the user's task to capabilities.
3. Select the smallest sufficient set of skills.
4. Prefer composing focused skills over loading broad skills unnecessarily.
5. State which skills are needed when this materially affects execution.

## Rules
- Do not assume a skill exists; verify availability.
- Do not install a skill merely because it might be useful.
- Prefer the narrowest relevant skill.
- When multiple skills overlap, choose the better-scoped one and avoid duplicate work.
