# Web Research

Use when current, external or niche information materially matters.

## Procedure
1. Form precise search questions.
2. Prefer primary and high-authority sources.
3. Cross-check important claims.
4. Record publication/update dates for time-sensitive information.
5. Summarize findings with source references.

Avoid treating search snippets as proof when the source page is available.
