# Fact Checking

Use when a task contains claims that could be wrong, outdated, ambiguous or consequential.

## Procedure
1. Identify claims requiring verification.
2. Prefer primary/official documentation and original sources.
3. Check dates, versions and scope.
4. Compare conflicting sources.
5. Label each result as verified, probable, uncertain or contradicted.

Never invent citations, version numbers or guarantees.
