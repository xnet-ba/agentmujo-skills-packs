# data-transformation

## Purpose
Transform, reshape and prepare datasets for analysis

## Guidance
- Inspect the dataset, analytical context, and intended outcome before working.
- Check data quality, assumptions, scope, and units.
- Prefer reproducible transformations and transparent calculations.
- Distinguish measured results from assumptions and recommendations.
- Use AgentMujo Core Skills for planning, research, debugging, verification, and reporting.
- Protect credentials, private datasets, and sensitive information.

## Expected Output
Report relevant findings, methods or transformations, validation performed, important results, and remaining limitations.
