# cloud-cost-optimization

## Purpose
Analyze and optimize cloud resource usage and cost

## Guidance
- Inspect the existing environment and configuration before making changes.
- Prefer reproducible, declarative, version-controlled workflows.
- Use least privilege and protect credentials and secrets.
- Make changes incrementally and keep them reviewable and reversible where practical.
- Use AgentMujo Core Skills for planning, research, debugging, verification, and reporting.
- Validate changes before deployment and verify the resulting state afterward.

## Expected Output
Report relevant findings, changes, validation performed, deployment/verification results, and remaining risks.
