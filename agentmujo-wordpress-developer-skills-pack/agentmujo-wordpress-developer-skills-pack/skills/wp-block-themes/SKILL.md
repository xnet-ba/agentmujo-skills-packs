# wp-block-themes

## Purpose
Develop and customize modern WordPress block themes.

## Guidance
- Inspect the current WordPress project and relevant configuration before changing it.
- Prefer WordPress-supported APIs and established project conventions.
- Make small, reviewable changes.
- Use AgentMujo Core Skills for planning, research, debugging, verification, and reporting.
- Test affected functionality before completion.
- Avoid exposing credentials, secrets, or private site data.

## Expected Output
Report relevant findings, changes made, tests performed, verification results, and remaining risks.
