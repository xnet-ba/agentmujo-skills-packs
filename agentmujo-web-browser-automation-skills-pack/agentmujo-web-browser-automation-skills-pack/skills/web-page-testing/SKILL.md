# web-page-testing

## Purpose
Validate web pages, links, forms and browser behavior

## Guidance
- Inspect the current page, browser state, URL, and scope before acting.
- Prefer the minimum browser actions needed for the task.
- Preserve useful evidence such as URLs, extracted values, and screenshots when appropriate.
- Use AgentMujo Core Skills for planning, research, debugging, verification, and reporting.
- Protect credentials, sessions, personal data, and other sensitive information.
- Verify important actions and outputs before completion.

## Expected Output
Report relevant findings, actions performed, evidence captured, verification results, and remaining risks.
