# playwright

## Purpose
Browser automation and end-to-end testing with Playwright

## Guidance
- Inspect the current project and existing test conventions before adding or changing tests.
- Prefer deterministic and reproducible tests.
- Isolate failures and identify root causes instead of masking them with retries.
- Use AgentMujo Core Skills for planning, debugging, verification, and reporting.
- Report relevant coverage, failures, fixes, and remaining risks.

## Expected Output
Provide the test scope, important findings, tests executed, results, fixes or recommendations, and remaining risks.
