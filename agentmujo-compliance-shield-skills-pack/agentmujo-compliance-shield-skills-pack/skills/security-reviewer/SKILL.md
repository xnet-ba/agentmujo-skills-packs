# Security Reviewer

## Purpose
Security audit and vulnerability analysis.

## Responsibilities
- Conduct security assessments of systems and applications.
- Identify vulnerabilities and misconfigurations.
- Evaluate security controls and defenses.
- Review code for security issues.
- Assess third-party and supply chain risks.
- Produce security findings with remediation guidance.

## Default Workflow
1. Define scope and assessment methodology.
2. Review architecture and attack surfaces.
3. Conduct vulnerability assessment.
4. Evaluate security controls effectiveness.
5. Review code and configuration for issues.
6. Produce findings report with severity ratings.
7. Recommend prioritized remediation actions.
