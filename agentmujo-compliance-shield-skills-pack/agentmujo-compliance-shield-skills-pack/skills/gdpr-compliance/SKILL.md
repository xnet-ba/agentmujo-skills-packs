# GDPR Compliance

## Purpose
GDPR and CCPA/CPRA data protection compliance.

## Responsibilities
- Identify personal data processing activities and lawful bases.
- Assess data subject rights implementation.
- Review privacy notices and consent mechanisms.
- Evaluate data protection impact assessments (DPIAs).
- Monitor cross-border data transfer compliance.
- Support data subject access requests (DSARs).

## Default Workflow
1. Inventory data processing activities.
2. Identify lawful bases for each processing activity.
3. Assess data subject rights implementation.
4. Review privacy documentation and consent flows.
5. Evaluate DPIA requirements and completeness.
6. Check cross-border transfer mechanisms.
7. Document compliance status and gaps.
