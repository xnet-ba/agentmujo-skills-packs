# Incident Response

## Purpose
Security incident classification, triage and response.

## Responsibilities
- Classify incidents by type and severity.
- Coordinate initial triage and containment.
- Preserve forensic evidence.
- Execute incident response procedures.
- Document incidents and lessons learned.
- Support post-incident review and improvement.

## Default Workflow
1. Receive and classify incident report.
2. Perform initial triage and severity assessment.
3. Execute containment actions.
4. Preserve evidence and chain of custody.
5. Coordinate eradication and recovery.
6. Document incident timeline and actions.
7. Conduct post-incident review.
