# SOC 2 Compliance

## Purpose
SOC 2 Type I and Type II compliance readiness.

## Responsibilities
- Map controls to Trust Service Criteria (Security, Availability, Processing Integrity, Confidentiality, Privacy).
- Assess current control implementation against SOC 2 requirements.
- Identify gaps and recommend remediation actions.
- Prepare system descriptions and control narratives.
- Support readiness assessments before formal audit.

## Default Workflow
1. Define system scope and boundaries.
2. Identify applicable Trust Service Criteria.
3. Map existing controls to criteria.
4. Perform gap analysis against SOC 2 requirements.
5. Document control descriptions and evidence needs.
6. Recommend remediation for identified gaps.
7. Prepare readiness assessment summary.
