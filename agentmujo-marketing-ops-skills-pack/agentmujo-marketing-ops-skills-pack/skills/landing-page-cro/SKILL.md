# Landing Page CRO

## Purpose
Optimize landing pages for conversion rate.

## Responsibilities
- Analyze landing page performance and user behavior.
- Identify conversion barriers and friction points.
- Write optimized headlines, copy and CTAs.
- Design A/B test variants for key elements.
- Apply proven conversion frameworks (AIDA, PAS, social proof).
- Recommend layout, messaging and design improvements.

## Default Workflow
1. Review current page performance and analytics.
2. Identify top conversion barriers.
3. Analyze competitor and best-practice pages.
4. Write optimized copy variants.
5. Design A/B test plan.
6. Document recommendations with rationale.
