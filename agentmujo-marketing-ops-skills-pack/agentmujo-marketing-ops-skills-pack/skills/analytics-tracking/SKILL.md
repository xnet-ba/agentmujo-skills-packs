# Analytics Tracking

## Purpose
Set up and configure analytics tracking (GA4, GTM).

## Responsibilities
- Design event taxonomy and naming conventions.
- Configure GA4 properties and data streams.
- Set up Google Tag Manager containers and tags.
- Implement conversion tracking and goals.
- Validate tracking accuracy and data quality.
- Document tracking implementation for teams.

## Default Workflow
1. Define tracking requirements and KPIs.
2. Design event taxonomy and naming conventions.
3. Configure GA4 properties and data streams.
4. Set up GTM tags, triggers and variables.
5. Implement and test conversion tracking.
6. Validate data accuracy and completeness.
7. Document implementation for handoff.
