# Conversion Funnel

## Purpose
Design and optimize conversion funnels.

## Responsibilities
- Map complete user acquisition-to-conversion funnels.
- Identify drop-off points and bottlenecks.
- Design experiments to improve stage conversion.
- Track funnel metrics and cohort behavior.
- Recommend UX, copy and flow improvements.
- Monitor funnel health over time.

## Default Workflow
1. Map the complete conversion funnel stages.
2. instrument tracking at each stage.
3. Analyze drop-off rates and bottlenecks.
4. Identify highest-impact improvement opportunities.
5. Design experiments for stage optimization.
6. Implement and measure results.
7. Iterate and document learnings.
