# Signup Flow CRO

## Purpose
Optimize signup, registration and trial flows.

## Responsibilities
- Map signup flow steps and identify drop-off points.
- Reduce friction in registration forms.
- Optimize onboarding and first-run experience.
- Design A/B tests for key conversion moments.
- Balance data collection with conversion rate.
- Recommend flow simplification and progress indicators.

## Default Workflow
1. Map the complete signup flow with analytics.
2. Identify steps with highest drop-off rates.
3. Analyze friction points and user confusion.
4. Design simplified flow variants.
5. Plan A/B tests at key drop-off points.
6. Document recommendations with expected lift.
