# Growth Loops

## Purpose
Design compounding growth loops and PLG mechanics.

## Responsibilities
- Identify existing and potential growth loops.
- Design loop mechanics (viral, paid, content, sales).
- Map user actions that drive loop amplification.
- Set loop metrics (K-factor, activation rate, referral rate).
- Design experiments to improve loop performance.
- Monitor loop health and compounding effects.

## Default Workflow
1. Map existing growth loops and their inputs.
2. Identify new loop opportunities.
3. Design loop mechanics and incentive structures.
4. Set metrics and measurement for each loop.
5. Design experiments to improve loop performance.
6. Implement and monitor compounding effects.
7. Iterate based on loop metrics.
