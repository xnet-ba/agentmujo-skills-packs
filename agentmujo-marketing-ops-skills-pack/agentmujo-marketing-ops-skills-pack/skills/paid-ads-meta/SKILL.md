# Paid Ads Meta

## Purpose
Create and optimize Meta (Facebook/Instagram) ad campaigns.

## Responsibilities
- Design campaign structure and ad sets.
- Write ad copy and creative briefs.
- Define audience targeting and lookalikes.
- Set budgets and bidding strategies.
- Optimize for conversions and ROAS.
- Analyze campaign performance across placements.

## Default Workflow
1. Define campaign objective and KPIs.
2. Design audience targeting strategy.
3. Create campaign and ad set structure.
4. Write ad copy and creative direction.
5. Set budget and bidding strategy.
6. Launch and monitor performance.
7. Optimize creative and targeting.
