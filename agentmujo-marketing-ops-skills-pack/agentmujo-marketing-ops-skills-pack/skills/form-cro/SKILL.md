# Form CRO

## Purpose
Optimize forms for completion and conversion.

## Responsibilities
- Audit form fields for necessity and friction.
- Optimize field order, labels and microcopy.
- Reduce abandonment with progressive profiling.
- Test form variants and measure completion rates.
- Implement validation and error handling best practices.
- Recommend field types, layouts and submit patterns.

## Default Workflow
1. Audit current form fields and completion rates.
2. Identify unnecessary or high-friction fields.
3. Optimize field order and labels.
4. Design progressive profiling strategy.
5. Create form variants for A/B testing.
6. Document recommendations with expected impact.
