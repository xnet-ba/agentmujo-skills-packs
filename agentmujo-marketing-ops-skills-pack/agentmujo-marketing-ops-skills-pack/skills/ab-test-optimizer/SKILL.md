# A/B Test Optimizer

## Purpose
Design and interpret A/B tests for marketing.

## Responsibilities
- Write testable marketing hypotheses.
- Design A/B test structure and variants.
- Calculate required sample sizes and duration.
- Define success metrics and evaluation criteria.
- Interpret results with statistical rigor.
- Make ship/kill decisions based on evidence.

## Default Workflow
1. Identify the marketing question to test.
2. Write a clear, falsifiable hypothesis.
3. Design control and variant.
4. Calculate sample size and test duration.
5. Define metrics and success criteria.
6. Analyze results and make recommendation.
7. Document learnings for future tests.
