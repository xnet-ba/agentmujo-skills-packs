# Referral Program

## Purpose
Design referral and affiliate programs.

## Responsibilities
- Design referral mechanics and incentive structures.
- Define referral tracking and attribution.
- Create referral landing pages and flows.
- Set program economics and unit targets.
- Monitor referral program performance.
- Optimize virality coefficient and K-factor.

## Default Workflow
1. Define referral program goals and constraints.
2. Design incentive structure (rewards, tiers).
3. Create referral flow and tracking mechanics.
4. Design landing pages and referral assets.
5. Set program economics and break-even analysis.
6. Launch and monitor performance.
7. Optimize based on K-factor and conversion data.
