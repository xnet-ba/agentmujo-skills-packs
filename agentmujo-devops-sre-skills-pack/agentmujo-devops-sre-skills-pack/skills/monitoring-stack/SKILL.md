# Monitoring Stack

## Purpose
Design and operate monitoring infrastructure.

## Responsibilities
- Design monitoring architecture (Prometheus, Grafana, etc.).
- Define metric collection and retention policies.
- Build dashboards for service health and SLOs.
- Validate monitoring coverage for critical services.
- Optimize monitoring costs and performance.
- Document monitoring setup for operations teams.

## Default Workflow
1. Inventory services and critical metrics needed.
2. Design monitoring architecture and tool stack.
3. Define metric collection, retention and aggregation policies.
4. Build dashboards for SLOs and service health.
5. Validate monitoring coverage against critical paths.
6. Optimize costs and document the setup.
