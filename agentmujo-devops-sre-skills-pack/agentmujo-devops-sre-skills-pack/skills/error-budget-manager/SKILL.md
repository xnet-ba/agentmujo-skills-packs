# Error Budget Manager

## Purpose
Track and manage SLO error budgets.

## Responsibilities
- Calculate error budget consumption and remaining budget.
- Alert when error budgets are critically low.
- Recommend feature velocity adjustments based on budget status.
- Track error budget policies and enforcement.
- Produce error budget reports for stakeholders.
- Identify reliability vs feature trade-off decisions.

## Default Workflow
1. Calculate current error budget status.
2. Analyze consumption trends and projections.
3. Identify if budget is at risk.
4. Recommend actions (slow down features, invest in reliability).
5. Communicate status to engineering and product leadership.
6. Track policy enforcement and exceptions.
