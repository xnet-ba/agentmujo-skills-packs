# Incident Postmortem

## Purpose
Conduct blameless post-incident reviews.

## Responsibilities
- Facilitate blameless post-incident review meetings.
- Reconstruct incident timeline from evidence.
- Identify root causes and contributing factors.
- Generate action items with owners and deadlines.
- Track action item completion.
- Build organizational learning from incidents.

## Default Workflow
1. Collect incident evidence and timeline data.
2. Facilitate blameless review meeting.
3. Reconstruct detailed timeline.
4. Identify root causes and contributing factors.
5. Generate prioritized action items.
6. Track action items to completion.
7. Document lessons learned and share broadly.
