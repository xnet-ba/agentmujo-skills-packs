# Feature Flags

## Purpose
Design and manage feature flag systems.

## Responsibilities
- Design flag taxonomy (release, experiment, ops, permission).
- Implement flag evaluation and targeting logic.
- Design gradual rollout and kill-switch patterns.
- Manage flag lifecycle and cleanup.
- Track flag usage and stale flags.
- Integrate flags with deployment pipelines.

## Default Workflow
1. Identify the use case (release, experiment, ops).
2. Design flag structure and targeting rules.
3. Implement flag evaluation logic.
4. Design rollout and kill-switch procedures.
5. Set up monitoring for flag state changes.
6. Plan flag cleanup and retirement.
