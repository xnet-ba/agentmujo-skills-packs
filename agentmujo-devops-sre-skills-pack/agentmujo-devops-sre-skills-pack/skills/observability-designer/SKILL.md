# Observability Designer

## Purpose
Design observability across metrics, logs and traces.

## Responsibilities
- Design the three pillars: metrics, logs and distributed traces.
- Define structured logging standards and conventions.
- Implement distributed tracing for request flow.
- Correlate metrics, logs and traces for debugging.
- Design observability for microservices and distributed systems.
- Optimize observability costs and storage.

## Default Workflow
1. Assess current observability maturity.
2. Define observability standards and conventions.
3. Design metrics collection and aggregation.
4. Implement structured logging pipeline.
5. Set up distributed tracing for critical paths.
6. Correlate signals for end-to-end visibility.
7. Optimize costs and document the design.
