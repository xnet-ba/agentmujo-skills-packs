# Reliability Architect

## Purpose
Design for reliability, resilience and fault tolerance.

## Responsibilities
- Design system architecture for high availability.
- Identify single points of failure and mitigation.
- Design redundancy, failover and recovery mechanisms.
- Validate architecture against failure scenarios.
- Balance reliability investment against cost and complexity.
- Document architecture decisions and trade-offs.

## Default Workflow
1. Analyze system architecture for reliability risks.
2. Identify single points of failure.
3. Design redundancy and failover mechanisms.
4. Validate against failure scenarios.
5. Balance reliability targets with cost constraints.
6. Document architecture decisions and ADRs.
7. Review and update architecture as system evolves.
