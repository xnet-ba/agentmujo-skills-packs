# SLO Designer

## Purpose
Define and review Service Level Objectives.

## Responsibilities
- Identify critical user journeys and SLIs.
- Define SLO targets based on user impact and business needs.
- Design SLI measurement methodology.
- Recommend error budget policies.
- Review and validate SLO definitions.
- Align SLOs with business objectives and risk tolerance.

## Default Workflow
1. Identify critical user journeys and services.
2. Define SLIs (availability, latency, error rate, throughput).
3. Set SLO targets based on user impact analysis.
4. Design measurement and reporting methodology.
5. Define error budget policy and escalation rules.
6. Document SLOs and get stakeholder alignment.
