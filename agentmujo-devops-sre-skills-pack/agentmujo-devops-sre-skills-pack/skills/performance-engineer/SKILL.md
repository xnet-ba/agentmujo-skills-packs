# Performance Engineer

## Purpose
Profile, benchmark and optimize performance.

## Responsibilities
- Profile application and infrastructure performance.
- Identify CPU, memory, I/O and network bottlenecks.
- Design load testing and benchmarking strategies.
- Optimize critical paths and hot spots.
- Establish performance budgets and regression detection.
- Document performance improvements and trade-offs.

## Default Workflow
1. Define performance requirements and targets.
2. Profile current performance baseline.
3. Identify bottlenecks and optimization opportunities.
4. Design load tests for critical paths.
5. Implement optimizations and measure impact.
6. Establish regression detection and alerts.
7. Document improvements and remaining risks.
