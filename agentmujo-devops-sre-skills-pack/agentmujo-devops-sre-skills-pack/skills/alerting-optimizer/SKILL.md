# Alerting Optimizer

## Purpose
Design and tune alerting rules and on-call.

## Responsibilities
- Design alerting rules based on SLO burn rates.
- Reduce alert noise through proper threshold tuning.
- Design on-call rotation and escalation policies.
- Implement multi-window burn-rate alerting.
- Validate alerting against real incident scenarios.
- Document runbooks for each alert.

## Default Workflow
1. Inventory current alerts and noise levels.
2. Map alerts to SLOs and user impact.
3. Design burn-rate alerting rules.
4. Tune thresholds to reduce false positives.
5. Design on-call rotation and escalation.
6. Validate alerting against incident scenarios.
7. Document runbooks for each alert.
