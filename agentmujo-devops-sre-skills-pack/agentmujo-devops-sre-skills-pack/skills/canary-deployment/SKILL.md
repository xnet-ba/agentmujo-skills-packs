# Canary Deployment

## Purpose
Design canary and progressive delivery pipelines.

## Responsibilities
- Design canary deployment stages and traffic allocation.
- Define automated rollback criteria and health checks.
- Implement progressive traffic shifting.
- Monitor canary metrics against baseline.
- Design blue-green and rolling deployment strategies.
- Integrate with feature flags for progressive delivery.

## Default Workflow
1. Define deployment strategy (canary, blue-green, rolling).
2. Design traffic shifting stages and percentages.
3. Define health checks and rollback criteria.
4. Implement automated metric comparison.
5. Design rollback procedures and triggers.
6. Document deployment runbook.
