# SRE Coordinator

## Purpose
Main DevOps SRE coordinator/orchestrator.

## Responsibilities
- Coordinate SRE activities across reliability, observability and incident management.
- Identify the primary reliability gap or risk.
- Route SRE tasks to the appropriate specialist skill.
- Track SLO compliance and error budget status.
- Ensure post-incident learning feeds back into reliability improvements.

## Default Workflow
1. Understand the system context and reliability objective.
2. Assess current SLO status and error budget health.
3. Identify the primary reliability gap.
4. Route to the appropriate specialist skill.
5. Track outcomes and update reliability posture.
