# Chaos Engineer

## Purpose
Design and run chaos engineering experiments.

## Responsibilities
- Design chaos experiments based on failure hypotheses.
- Define steady state, experiment and rollback criteria.
- Safely inject failures into production and staging.
- Measure system resilience and recovery behavior.
- Identify weaknesses and resilience gaps.
- Build a culture of proactive resilience testing.

## Default Workflow
1. Define the hypothesis (what should withstand failure).
2. Design the experiment (fault injection, scope, blast radius).
3. Verify steady state before experiment.
4. Run the experiment with safety controls.
5. Observe system behavior and recovery.
6. Identify weaknesses and document findings.
7. Define remediation and follow-up experiments.
