# DevOps SRE Skill Design

DevOps SRE skills should:

- focus on reliability, not just deployment velocity
- make SLO targets and error budgets explicit
- produce measurable, data-driven recommendations
- distinguish between reactive operations and proactive reliability
- verify monitoring and alerting against real incident scenarios
- document runbooks for every significant operational procedure
- balance reliability investment against feature velocity
- validate capacity plans against actual load patterns

SRE skills complement — not replace — general DevOps and Cloud infrastructure skills.
